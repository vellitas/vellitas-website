# Artwork notes

The website uses original AI-generated raster artwork created for this project:

- `assets/hero-globe.webp`: global public-certificate field used in the hero.
- `assets/patent-layers.webp`: layered certificate/context illustration used in the patent section.
- `assets/og-image.jpg`: social-sharing preview based on the approved hero concept.

The interface, typography, labels, buttons, diagrams, and icons remain code-native. No third-party stock images, icon libraries, or externally hosted fonts are required.

## Vellitas logo system

The canonical vector geometry was traced from the owner-supplied 1883×611 transparent PNG
(`vellitas-logo-blue.png`). That source was selected over the smaller WordPress JPEG derivatives
because it preserves the cleanest edges, the original proportions, and the flat source colors.

- `assets/vellitas-logo.svg`: primary blue-and-gray logo for light surfaces.
- `assets/vellitas-logo-on-dark.svg`: the same geometry with a light wordmark and shield lines for dark surfaces.
- `assets/vellitas-shield-blue.svg`: standard Vellitas assessment mark (`#0f75bc`).
- `assets/vellitas-shield-green.svg`: passing status (`#32b66b`).
- `assets/vellitas-shield-yellow.svg`: caution status (`#e5a812`).
- `assets/vellitas-shield-red.svg`: immediate-action status (`#df3f3f`).
- `assets/favicon.svg`: shield-only browser and install icon.

The four report shields share one geometry and differ only in the right-side status color. They have
transparent backgrounds and can be used in reports without the Vellitas wordmark.
